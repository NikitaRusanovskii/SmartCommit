# SmartCommit
a tool for smart commit creation

## INSTRUCTION:
    1. Download ? install ollama
    2. Install requirements.txt with ```pip install -r requirements.txt```
    3. Pull model, that you wanna use to generate commit name
    4. Change variable MODEL in main.py
    5. Run pip install -e in the project's root directory.
    6. Use "smc run" to run tool.
